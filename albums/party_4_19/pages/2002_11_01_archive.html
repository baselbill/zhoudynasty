If you got a min, try this!
Don't cheat by reading all the steps, just follow each step or you'll ruin the surprise.

1. How many times would you like to eat out for dinner in a week? Pick something from 1 to 7.

2. Now take that number of meals and double it.

3. Ok now add 5 more to that number of meals.

4. Got it? Ok now multiply this new number by 50...I'll wait for you to grab the calculator.

5. Ok now if you already had your birthday this year, add 1752. If you haven't, add 1751.

6. Now last step, subtract this number by the year in which you were born.

7. Ok now you should get a 3 digit number. The first digit is how many times would you like to eat out for dinner in a week. The last two digits is your age!
