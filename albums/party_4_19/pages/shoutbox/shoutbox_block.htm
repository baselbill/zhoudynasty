IP blocking
The following IP addresses are blocked from posting on the shoutbox.
{start blocked} {end blocked}
{ip} Unblock
Note that IP blocking is not effective against modem users or anyone with dynamic IP address.
Most broadband users have static IP addresses so this should provide some blocking against troublesome users.
Block a user
Enter the IP address of the user you want to block.
Entering an IP address that is already in the list will unblock that address.
